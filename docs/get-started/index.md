# Get Started

Install the Python package, then run a small example on a local CPU. The single-FOV
demo processes tiny synthetic images to molecule-level CSVs, and the multi-FOV / sample
demo, still to be written, will process a small synthetic sample of several FOVs. The
single-FOV demo needs no microscopy data, MATLAB, Snakemake or GPU.
