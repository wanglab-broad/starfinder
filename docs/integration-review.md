# Integration review from saved evidence

An integration packet combines attributable software acceptance with the
remaining scientific and operational work. It does not rerun processing to fill
missing evidence. Follow the [saved-evidence interface](sample-export-contract.md#saved-evidence-and-delivery-interface)
and the current issue's approved scope. Run-specific renderers, snapshots,
trajectory data, logs and reports belong in the external issue artifact directory.
Reusable controller telemetry belongs in the runner repository.

## Scientific coverage

Pin the source revision, dirty patch when applicable, environment, dataset
catalog versions and each producer's evidence hashes. Include raster reduction
and fallback, preserved populations and source links, exact checkpoint/export
round trips, actual consumer execution, measured storage and bounded backend
comparisons. Every condition needs an English purpose, expected and observed
values, units/tolerances and an honest execution status. Present representative
saved images alongside numerical tables; a generic terminal log is supplementary.

A deferred consumer remains failed or unexecuted in its own row. An explicitly
approved reporting scope may accept disclosure of that gap; it cannot turn the
consumer into a pass or complete the original milestone. Missing other required
execution blocks delivery. Development fixtures do not establish biological
truth, empirical calibration or accuracy on real data.

## Execution coverage

Keep one node per issue, colored by milestone. Derive dependency and relationship
edges from saved issue snapshots, and execution-order edges from actual session
timestamps. Retain separate attempt details, including interruptions, repairs
and resumptions. Record requested models/efforts separately from emitted identity.

Deduplicate copied invocations by session ID and start time. Verify whether usage
counters are cumulative before subtracting successive observations; count the
latest cumulative value once per unique session. Cached input is part of input,
and reasoning is part of output. Missing counters are unknown. Attribute
coordinator overhead only when the evidence permits it; otherwise retain a
separate shared total. Token consumption is not a subscription charge.

Distinguish issue elapsed time, active agent wall time and check time; checks
inside a worker overlap its wall time. Compare batches only for common metric
definitions and disclose different workloads, models, test suites and coverage.
Do not infer causal efficiency gains from unlike jobs.

## Delivery and final read-back

The controller supplies completed check records and the committed revision to
the owning renderer. Verify exact log hashes and execution/reuse identities,
reject missing required checks and preserve previous packets. Open the standalone
English HTML in an offline browser, verify essential figures/tables and capture
screenshots. Display full host paths and copy/open commands as code.

Worker previews, committed packets, independent acceptance and final controller
synchronization are distinct records. A report cannot certify its own future
review or terminal state. Append the actual acceptance/read-back and durable
terminal evidence after completion, preserving the earlier snapshot. Human
review, merge/publication and scientific acceptance remain separate actions.
