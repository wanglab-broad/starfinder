# MATLAB API

**Coverage planned:** generated MATLAB reference and cross-references to the Python
backend. MATLAB-domain generation is not configured in this foundation.

Existing implementations are in
[`src/matlab/`](https://github.com/wanglab-broad/starfinder/tree/dev/src/matlab),
with `STARMapDataset.m` as the main orchestrator. See the
[workflow examples](https://github.com/wanglab-broad/starfinder/blob/dev/example/README.md)
for existing entry points. Building the current documentation does not run MATLAB
or require a MATLAB license.
